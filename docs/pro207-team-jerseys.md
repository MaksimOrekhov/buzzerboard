## Как обновить редакционный срез

1. Открыть страницу комплекта или индивидуальную запись календаря. Сверить команду, сезон и точное название категории. В LockerVision поле `gameid` привязывает запись к конкретной игре. Архивный мотив из другого города или эпохи относится к франшизе, которая выпустила комплект в указанном сезоне.
2. Сохранить `canonicalTeamId`, `eraFrom` по справочнику истории и `jerseyId` вида `nba:jersey:<team>:<season>:<type>`. Внести собственное описание, ссылку и дату проверки. `announcedOn` хранит дату объявления, `outfitDate` дату одной записи в календаре формы. Даты выпуска, первое фактическое использование и полный срок ношения не выводятся из даты объявления или одной запланированной игры.
3. Внести цвета только при сверке конкретного выпуска. Для десяти записей каталога без сверенной палитры (одна в сезоне 2026/27) интерфейс показывает текстовый статус. Повторно проверить 85 оставшихся текущих пар по индивидуальным публикациям NBA, клубов и календарю. Добавлять архивные сезоны только с отдельным подтверждением.
4. При появлении проверяемого изображения отдельно подтвердить лицензию файла, дизайн, товарные знаки и образ человека при его наличии. Связать проверенную запись [общего манифеста](../src/entities/nba/teamMediaManifest.ts) по `jerseyId`. Указать автора, источник, лицензию, изменения и дату. Для разрешения дизайна указать ссылку на основание и отдельные статусы. Манифест содержит 19 материалов при лимите 30.
5. Выполнить `pnpm test`, `pnpm media:check` и `pnpm run visual:pro171 --compact`. Обычный CI прогоняет браузерные сценарии на всех заданных размерах и сохраняет выбранные скриншоты. Все кадры собираются по запросу через workflow `visual-audit`.

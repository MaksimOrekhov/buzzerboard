# PRO-190 · Читаемость статистики

На странице матча порядок везде одинаковый: гости слева или сверху, хозяева справа или ниже. В заголовке эмблема и название каждой команды собраны вместе; счёт расположен между командами, четверти вынесены в компактную таблицу. Сравнение ограничено по ширине. Полосы показывают величину, а не качество результата: для бросков шкала 0–100%, для остальных строк — от нуля до большего из двух значений. Если одного значения нет, полосы не рисуются.

Полноширинные таблицы игроков стоят друг под другом. Основные поля доступны сразу, броски и защитные показатели переключаются кнопками. Это оставляет место для имён даже на узких экранах. Броски сортируются по проценту, пустые значения всегда идут в конце; DNP и неизвестное участие обозначены отдельно. Статистика сезона, последние матчи и лидеры команд используют ту же шкалу, без изменения палитры, Manrope и оболочки Design System v2.

## Локальный запуск с существующим D1

В корне репозитория выполните `pnpm build`. Затем запустите команды в двух терминалах. Проверяйте наличие исходных баз перед запуском: эти команды используют уже существующие кеши, а не наполняют новые.

```sh
XDG_CONFIG_HOME=.wrangler/config WRANGLER_WRITE_LOGS=false WRANGLER_SEND_METRICS=false \
  pnpm exec wrangler dev --ip 127.0.0.1 --port 8787 --persist-to .wrangler/state \
  --var NBA_GAMES_PROVIDER_ORDER:bbs --var BBS_REFRESH_ENABLED:false \
  --var DUNKAPI_REFRESH_ENABLED:false --var DUNKAPI_BOX_SCORE_REFRESH_ENABLED:false
```

```sh
XDG_CONFIG_HOME=.wrangler/config WRANGLER_WRITE_LOGS=false WRANGLER_SEND_METRICS=false \
  pnpm exec wrangler dev --ip 127.0.0.1 --port 8788 --persist-to /private/tmp/pro189-wrangler-state \
  --var NBA_GAMES_PROVIDER_ORDER:bbs --var BBS_REFRESH_ENABLED:false \
  --var DUNKAPI_REFRESH_ENABLED:false --var DUNKAPI_BOX_SCORE_REFRESH_ENABLED:false
```

## Крупные снимки

Локальные PNG в `artifacts/pro-190/visual/{before,after}/`: полные страницы на 1440 и 375 CSS px, а также отдельные фрагменты счёта, сравнения, таблицы игроков и профиля. До — `f148180`, после — ветка PRO-190. Реальные данные и изображения не публикуются в Git/CI.

```sh
PW_EXECUTABLE_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' \
  node scripts/pro190-local-visual.mjs after
```

Проверка использует только локальные GET; Chrome блокирует обращения за пределы двух локальных портов. В `measurements.json` записаны размеры шрифтов и переполнение для 375/768/1024/1280/1440/1920 CSS px.

# PRO-217 · UI/UX-аудит BuzzerBoard

Базовая версия — main на `1e58f1d419d4d752eee21186dbfda31f2e7179af`. В CI артефакт
`buzzerboard-pro171-synthetic` содержит `comparison.html`, снимки `baseline/` и
`synthetic/`, а также `checks.json` для обоих прогонов. После распаковки в
`comparison.html` можно открыть пары в исходном размере. Для нативных селектов Chromium
сохраняет закрытый контрол. Открытые меню истории и тренеров показаны в снимках PR.

## Покрытие и воспроизведение

- Все 11 типов маршрутов. У CHI, LAL, MIN, NYK и POR сняты обзор, история и тренеры. NYK и
  POR проверены с пустой галереей. POR — без лицензированного портрета.
- Chromium на 320, 375, 620, 768, 1024, 1280 и 1440 px, включая 320 × 600 и 1440 × 600.
  Проверены длинные названия, загрузка, пустые ответы, ошибка, устаревший снимок, избранное,
  отсутствие бокса, горизонтальный скролл таблиц, текущий режим спойлеров и защищённые
  результаты в DOM/ARIA.
- Сохранены семантические таблицы, кнопки сортировки, флажки сравнения, числовые поля
  и раскрываемые детали источников. Продуктовые dropdown используют AppSelect.
- Проверены порталы и границы календаря, диалога и выпадающих списков, выбор клавишами,
  Escape, Tab и возврат фокуса. Прямые ссылки, обновление и back/forward проверены в SPA.
  Отдельного серверного рендера у приложения нет.
- В CI используется Vite с локальными фикстурами и проверенными медиа. GET к API
  перехватывается браузером, внешние запросы блокируются. Ссылки на источники в подписях
  сохранены. Ошибки декодирования и сохранение ссылки на лицензию проверяет браузерный тест.
- Локально подготовьте отдельный checkout базового SHA с `pnpm install --frozen-lockfile`.
  В рабочей ветке запустите `BUZZERBOARD_VISUAL_BASELINE_ROOT=/absolute/path/to/base pnpm run visual:pro171`,
  затем `pnpm run visual:pro171`. Пары появятся в `artifacts/pro-171/comparison.html`.

Ручное принятие владельцем и независимое ревью остаются этапами перед merge.
